\begin{abstract}
本文研究：在混合声音到达之前，仅由历史声景因果预测的海洋背景，能否帮助分离突发声学事件。
FC-BSR 从此前的三分之一倍频程谱预测当前背景，并通过特征拼接、特征线性调制（FiLM）或交叉
注意力注入 BS-RoFormer。三级实验把机理选择与真实场景证据分开：在有精确合成声轨时，FiLM
相对无条件分离器提高 0.34 dB SI-SDRi；在 42 小时连续真实水听器背景与注入目标上，5 秒至
10 分钟的四种因果先验均有收益，5 秒窗提高 1.226 dB，但三个尺度的最佳预测仍是 persistence；
在没有隔离声轨的 1225 个真实鲸声事件上，FC-BSR 相对匹配的 BS-RoFormer 将残余事件概率从
.523 降至 .507，同时区间外改动略有增加。结果支持预测条件的价值，但尚不支持无条件的保真度
或部署结论。
\end{abstract}

海洋声学，源分离，声景预测，BS-RoFormer，无参考评估

\section{引言}
海洋背景随航运、天气、生物活动和季节变化\cite{miksisolds2013indian}。传统分离器需要从同一
混合声音中同时推断目标与变化背景。本文改为提供一个严格因果的先验：只使用混合声音到达前的
观测，估计此时应出现的背景频谱。科学问题写为
\begin{equation}
 S_{t-H:t-1}\xrightarrow{P_\psi}\widehat S_t,\qquad
 x_t=N_t+\alpha s_t\xrightarrow{F_\phi(\cdot\mid\widehat S_t)}(\hat s_t,\hat N_t).
\end{equation}
模型从不观察当前干净背景 $N_t$。

Conv-TasNet 与 DPRNN 等时域模型\cite{luo2019convtasnet,luo2020dprnn}、SepFormer 与
TF-GridNet 等注意力模型\cite{subakan2021sepformer,wang2023tfgridnet}以及子带模型
\cite{luo2023bsrnn,lu2023bsroformer}提供了强大的仅混合输入骨干；混合 Transformer
\cite{rouard2023htdemucs}与 MixIT\cite{wisdom2020mixit}分别扩展了架构和无隔离声轨训练。
这些工作均未把下一时刻背景的预测作为条件。FiLM\cite{perez2018film}、交叉注意力
\cite{vaswani2017attention}和跨模态分离\cite{zhao2018pixels}给出三种候选接口；DeepAR、
N-BEATS、DLinear 与 PatchTST 则覆盖递归、基展开、线性和分块预测
\cite{salinas2020deepar,oreshkin2020nbeats,zeng2023dlinear,nie2023patchtst}。

本文贡献为：（1）带三种匹配条件消融的因果预测条件 BS-RoFormer；（2）从完整真值代理背景、
真实背景到真实事件的防泄漏分层评估；（3）不同信号强度、信号分布和 5 秒、30 秒、1 分钟、
10 分钟尺度的实验；（4）在真实事件上直接比较 FC-BSR 与无条件 BS-RoFormer 的无参考检验。

\section{方法}
\subsection{背景预测与分离}
历史三分之一倍频程声级（TOL）$S_{t-H:t-1}\in\mathbb R^{H\times F}$ 只用训练集统计量归一化。
残差 GRU 预测
\begin{equation}
 z_t=\operatorname{LN}(\operatorname{GRU}(S_{t-H:t-1})),\quad
 \widehat S_t=S_{t-1}+g_\psi(z_t).
\end{equation}
残差零初始化精确表示 persistence；只有当验证 MAE 优于该基线时才保留学习式预测，符合点预测
的规范比较\cite{gneiting2011pointForecast}。

BS-RoFormer 将混合 STFT 映射为子带 token $X_k$。在轴向 Transformer 前的相同位置比较
\begin{align}
\text{拼接：}\widetilde X_k&=X_k+f([X_k;P_k(\widehat S_t)]),\nonumber\\
\text{FiLM：}\widetilde X_k&=(1+\tanh\gamma_k)\odot X_k+\beta_k,\label{eq:inject}\ \ \\
\text{交叉注意力：}\widetilde X&=X+\operatorname{Attn}(X,E(\widehat S_t),E(\widehat S_t)).\nonumber
\end{align}
残差分支从零开始，使各模型拥有相同的初始音频映射。损失由波形 $L_1$、多分辨率复数 STFT
损失组成；仅代理背景实验加入 $0.2\|\widehat S_t-S_t\|_1$。真实波形实验先按验证预测误差选出
预测器并冻结，再训练分离器。

\subsection{数据与证据层级}
第一层使用 NOAA--Navy SanctSound 小时级 TOL 产品\cite{noaa2020sanctsound}。MB03 部署
01--02/03/04 分别为训练/验证/测试集。随机相位逆变换仅产生受控频谱代理，不能称为还原音频。
目标包含谐波、啁啾、非谐波与 FM 音调、脉冲和带限噪声。分布位移用 Jensen--Shannon（JS）
散度\cite{lin1991divergence}，另以频谱熵描述弥散程度。

第二层直接使用 42 小时连续 8-kHz 水听器 WAV，其中 12/6/24 小时用于训练/验证/测试。一秒
周期图聚合为 23 个 TOL 频带和 5 秒、30 秒、1 分钟、10 分钟窗口。下一个真实背景波形 $N_t$
叠加合成目标，因此仍有精确参考；每种尺度都覆盖一小时因果历史。

第三层使用按日期隔离的 2-kHz DCLDE 2013 露脊鲸录音\cite{gillespie2019dclde}。强事件标注
可支持检测\cite{shiu2020marine}，但不存在隔离的事件/背景声轨。仅在干净训练窗口中注入合成
upcall；1225 个未修改的真实阳性片段只用于测试。两种模型共享样本、随机种子、初始权重、
2500 步预算与仅验证集选点规则。

\subsection{实验协议与指标}
全部比较在波形层面严格配对：混合时刻、目标抽样、SNR、随机种子、分离器骨干初始权重、优化器
日程和检查点规则均相同。部署 03 负责全部选型，部署 04 只评估一次。连续音频按时间划分，DCLDE
按录音日划分，重叠窗口不能跨集合。特征归一化只用训练录音拟合，历史编码器严格截止于 $t-1$。

有完整参考的两层报告 SI-SDR、相对输入混合的改善、残余背景 SI-SDR、预测 MAE、参数量和实时
因子（RTF）。SI-SDR 采用尺度不变投影而非原始 BSS Eval 分解\cite{vincent2006sdr,leroux2019sdr}。
不确定性由测试片段上的固定种子配对 bootstrap 给出。多样性实验固定输入 SNR 为 0 dB，每个
信号族取 128 个严格配对样本，避免强度混淆形状。本文同时报告方向性
$D_{\mathrm{KL}}(p\|q)$ 与有限对称的 JS 散度，但只把它们解释为频谱位移，而不是语义多样性。

\section{实验与结果}
\subsection{受控选型与信号分布}
第一层各模型每个训练部署使用 4000 个样本、训练 2000 步，SNR 从 $[-12,12]$ dB 均匀抽样。
表\ref{tab:ablation}只按验证集选择 FiLM；其 0-dB 配对增益为 0.34 dB（95\% bootstrap 区间
$[0.21,0.48]$）。逐频带缩放与偏置可直接表达“此处是预期能量”；拼接需要压缩加倍特征，而
交叉注意力需要从粗频谱中学习对齐。

在输入 SNR 为 $-12,-6,0,+6,+12$ dB 时，FiLM 的 SI-SDRi 依次为
$7.30,6.95,5.81,3.51,-0.10$ dB；$+12$ dB 时绝对 SI-SDR 仍为 11.94 dB。在 768 个严格配对、
固定 0-dB 样本上，FiLM 将 5.36 提高到 5.70 dB。增益与 JS 位移相关性很弱（$-0.085$），
但与频谱熵正相关（$0.145$），最高熵五分位增益 0.80 dB。因此 KL/JS 能扩大覆盖范围，却不能
单独预测先验何时有效。图\ref{fig:signals}展示弥散目标的历史、当前谱、混合与分离频谱。

分族结果支持上述解释：带限噪声增益 0.54 dB（$[0.19,0.92]$），脉冲列 0.47 dB
（$[0.16,0.79]$），FM 目标 0.43 dB（$[0.08,0.82]$）。相反，增益从最低 JS 五分位的
0.54 dB 降到最高五分位的 0.00 dB。更大散度扩展了测试覆盖，却不保证收益；与可预测海洋频带
的重叠及源内弥散程度更可能解释条件先验何时有效。

\subsection{连续真实背景}
预测器最多训练 2500 步，分离器训练 3000--5000 步。表\ref{tab:windows}每种尺度含 1024 个
配对留出片段。所有置信区间均不含零，但彼此重叠。只有 5 秒选择学习式 GRU（MAE 比
persistence 低 1.4\%）；30 秒、1 分钟、10 分钟都选择 persistence。时间相关背景有用，但现有
数据不能证明复杂动态预测普遍必要。

从 5 秒到 10 分钟的验证 MAE 依次为 1.366、0.782、0.687、1.371 dB。10 分钟训练集只有
60 个不同的下一窗口目标，因而预测器严重过拟合。四个分离器均通过五档 SNR 工程门槛，RTF
约为 .0024。因此，正面结论是时间相关条件有价值，而不是已显著排定时间分辨率优劣，或证明
GRU 普遍胜过 persistence。

\subsection{没有分离真值的真实事件}
由于没有隔离声轨，完整参考指标不可用。参考学习式无参考指标
\cite{kilgour2019fad,grais2019referenceless}及语义音频嵌入\cite{wu2023clap,xiao2024clapscore}，
我们训练、校准并冻结二分类器（测试 AUROC .9704）。令 $\hat N=x-\hat s$ 保证混合一致性，再将
$\hat s$ 从 $-60$ dB 逐级恢复到 0 dB，并要求事件概率单调恢复。Identity 与 all-to-event 对照
排除平凡解，标注区间外相对变化检验背景保留。

分类器的平衡清单含 5292/2696/2676 个训练/验证/测试片段；确定 upcall 为阳性，阴性排除确定与
可能 call 及其 2 秒边界。测试平均精度为 .9738，F1 为 .9196。每个合格目标只接收此前八个
8 秒、30 频带频谱。残差 GRU 将验证预测 MAE 从 2.081 降到 1.921 dB，随后冻结。在任何模型
接触真实事件测试集前，BS-RoFormer 与 FC-BSR 的受控验证 SI-SDRi 分别为 13.871 与 13.925 dB。

FC-BSR 将残余事件概率再降低 .0160；按三个录音日均值配对 bootstrap 得
$[-.0210,-.0132]$。事件声轨概率与单调率在不确定性内不变，但区间外改动增加 .00662

不能识别事件区间内的相位或波形失真。

\section{讨论与结论}
证据支持的是逐层嵌套结论：完整真值实验选择 FiLM；真实背景实验确认四种子小时尺度的因果先验
均有效；真实事件实验说明它在无条件 BS-RoFormer 之上有语义收益。但学习式预测并非普遍更好，
因为四个尺度中有三个选择 persistence；分类器指标也无法恢复缺失的波形保真真值。后续仍需多
站点、多季节、更多 10 分钟训练目标、多随机种子，以及隔离声轨或更强的局部参考。

这一顺序也约束了解释。第一层可识别条件机制，但使用相位合成背景；第二层去掉该假设，同时保留
合成目标与精确声轨；第三层去掉合成测试目标，却必然失去完整参考保真指标。跨层一致性强于任何
单一结果，但各层指标不能互换，尤其不能把分类器事件移除当作 SI-SDR 的替代品。

模型通过实用门槛：总体 SI-SDRi 至少 5 dB，SNR $\leq0$ dB 时改善至少 3 dB，强信号绝对
SI-SDR 至少 8 dB，实时因子低于 1。本地前端可接收因果 TOL 历史与 WAV，显示预测结果，并试听/
下载目标与残余背景；RTX 3060 上 10 秒分块处理 RTF 为 .043。这说明系统已适合实验检查，但仍需
明确区分工程可用与野外部署。
