\begin{abstract}
常规海洋声音分离器只能从当前混合信号中估计持续变化的背景。本文研究：在混合信号到达前，
根据历史声景严格因果地估计当前期望背景，能否提供额外的有效证据。FC-BSR 从历史三分之一
倍频程声级预测当前频谱，并通过拼接、FiLM 或交叉注意力注入 BS-RoFormer 子带 token。
为避免混淆不同科学主张，实验按三层证据展开。第一层在具有完整真值的代理背景上选择 FiLM；
它在 768 个六类配对样本上相对无条件模型增加 0.34 dB SI-SDRi，而 JS 散度不能单独预测收益。
第二层把背景替换为 42 小时连续真实水听器录音，同时保留合成目标以获得完整真值。四种时间
先验在 1024 个留出片段上均改善分离，5 秒尺度增益为 $+1.226$ dB（$[1.082,1.381]$）；但只有
5 秒学习预测优于 persistence，因此该层更支持“时间相关条件有用”，而非“学习预测普遍更优”。
第三层使用 1225 个没有隔离声轨的真实鲸声事件做匹配无参考比较：FC-BSR 把残余事件概率从
.523 降至 .507，事件声轨证据不变，但区间外改动从 .0956 增至 .1022。因此，预测先验改善了
真实事件的语义移除，却没有在所有保真指标上获胜。
\end{abstract}

\section{引言}
被动声学背景会随航运、天气、生物活动和季节变化。只观察当前混合信号的分离器必须同时
估计目标与背景。长时间声景预测提供了另一个严格因果的信息源：混合信号到达前，背景本应
是什么样。本文假设该先验可能帮助分离器抑制可预测能量，同时保留意外出现的注入声源。

本文将 Band-Split RoPE Transformer（BS-RoFormer）\cite{lu2023bsroformer} 与因果循环
预测编码器结合，并按“受控性到真实性”组织证据。第一层使用 TOL 构造的背景代理和完整声轨
真值选择注入机制、分析信号分布；第二层只把背景替换成连续真实水听器录音，仍通过注入合成
目标保留完整真值；第三层再把测试目标替换成真实鲸声，由于不再有隔离声轨，改用语义指标和
部分真值约束。每层只回答自身能够识别的问题，不能互相替代。

本文贡献包括：具有拼接、FiLM 和交叉注意力匹配消融的可微预测条件接口；同时报告预测误差、
配对分离、语义移除、保真约束、统计不确定性与运行时间的三层防泄漏协议；带频谱偏移和频谱熵
分析的六类信号生成器；以及可供检查、试听和下载结果的本地前端。

\section{数据与分层评估设计}
三层实验有意使用不同观测。“真实背景”表示噪声波形来自录音而非频谱重建；“真实目标”表示
事件本身来自录音，二者不能混为一谈。第一层的背景和目标均为合成且有完整真值；第二层使用
真实背景、合成目标和完整真值；第三层同时使用真实背景与真实目标，但没有隔离分离真值。

我们使用 NOAA--Navy SanctSound 小时级 TOL 产品\cite{noaa2020sanctsound}。
MB03\_01 与 MB03\_02 用于训练，MB03\_03 用于验证，MB03\_04 为留出测试集。
时刻 $t$ 的样本只有在此前 $H$ 小时及当前小时均有限且严格逐小时连续时才有效。归一化
统计量仅由两个训练部署拟合。

公开 TOL 是聚合产品，无法确定波形相位。对当前频谱 $S_t$，我们在 FFT 频点上插值其
dB 包络，使用固定种子采样随机相位和类 Rayleigh 幅度抖动，逆 FFT 后归一化 RMS，
得到背景代理 $n_t$。该代理保留粗粒度实测频谱包络，但不保留瞬态、相位或小时内事件，
不能表述为恢复的现场原始音频。

现场实验直接使用对应的连续 8 kHz SanctSound 水听器录音：MB03\_01、02、03 各 6 小时，
以及连续 24 小时的 MB03\_04 测试日，共 42 小时。先对 1 秒 Hann 周期图在 25--4000 Hz 的
23 个三分之一倍频程积分，再平均为 5 秒特征，并在功率域聚合为 30 秒、1 分钟或 10 分钟。
该实验不合成任何背景波形相位。

原始注入信号 $s_t$ 采用 MINUS 中的可控合成逻辑：谐波分音、带限噪声、起音/释音包络与
低频幅度调制。广分布配置新增扫频、非谐波、多脉冲、调频与带限噪声，并放宽载频、调制、
包络、瞬态及噪声占比范围。每个样本确定性地重采样信号族、参数和信号背景比。混合信号为
$x_t=n_t+s_t$，并通过共同缩放避免削波。

第三层另用具有强标注的 2 kHz DCLDE 2013 露脊鲸录音。其按日划分方法和无参考指标在
第~\ref{sec:real-events-zh}节定义；该数据不与 SanctSound 混合。

\section{方法}
令 $S_{t-H:t-1}\in\mathbb{R}^{H\times F}$ 为归一化历史 TOL。GRU 产生
\begin{align}
 z_t &= \operatorname{LN}(\operatorname{GRU}(S_{t-H:t-1})),\\
 \widehat S_t &= g_\theta(z_t).
\end{align}
编码器只读取截止 $t-1$ 的观测。三种注入方案均令 $c_t=\widehat S_t$；基线删除预测器。

BS-RoFormer 将混合信号 STFT 频点变为子带 token
$X\in\mathbb{R}^{B\times T\times K\times D}$。令 $P_k(c_t)$ 为逐子带投影，$E(c_t)$ 为预测
频率箱 token 序列。我们在时间/频率 Transformer 之前比较三个残差注入算子：
\begin{align}
\text{拼接：}\widetilde X_k &= X_k+f([X_k;P_k(c_t)]),\\
\text{FiLM：}\widetilde X_k &= (1+\tanh\gamma_k(c_t))\odot X_k+\beta_k(c_t),\\
\text{交叉注意力：}\widetilde X &= X+\operatorname{Attn}(X,E(c_t),E(c_t)).
\end{align}
三条残差支路均初始化为零，使所有实验从相同音频映射开始。拼接先把局部特征宽度加倍再用
MLP 融合；FiLM 直接改变子带 token 的尺度与偏置；交叉注意力学习音频与预测频率箱之间的
内容相关对齐。

代理背景受控实验的端到端目标为
\begin{equation}
 \mathcal L=\mathcal L_{\mathrm{wave}}
 +\tfrac12\sum_r\mathcal L_{\mathrm{complex\ STFT},r}
 +\lambda\lVert\widehat S_t-S_t\rVert_1,
\end{equation}
条件模型取 $\lambda=0.2$。在第一层实验中，两种损失都反向更新预测编码器。连续真实背景和
真实事件实验则先按验证预测误差选择预测器，再冻结它并训练分离器。这个有意的差别避免分离
损失破坏可独立度量的预测准确率，同时保持相同的条件接口。

\section{代理背景上的受控实验}
第一层证据在完整真值下回答哪种条件算子有效。它用于机制选型，尚不能证明原始海洋波形或
真实目标事件上的收益。

所有方案共享样本、合成种子、优化器日程、模型宽度、分离器核心初始权重和检查点规则。
验证 SI-SDRi 最高的检查点仅在 MB03\_04 上评估一次。SI-SDR 采用尺度不变投影形式，
SI-SDRi 为输出 SI-SDR 减去混合信号 SI-SDR。我们还报告残余海洋背景 SI-SDR、
预测 MAE、实时因子（RTF）、参数量和配对胜率。区间使用固定种子的逐样本配对 bootstrap。
盲源分离评估背景见 Vincent 等\cite{vincent2006sdr}。

分布偏移计算先把波形功率汇聚到 $K=64$ 个对数频率箱并归一化为 $p$，以原始窄谐波
生成器 512 次采样的均值分布为 $q$。除方向性 $D_{\mathrm{KL}}(p\Vert q)$ 外，主指标采用
有限且对称的 JS 散度\cite{lin1991divergence}：
\begin{equation}
 D_{\mathrm{JS}}(p,q)=\tfrac12D_{\mathrm{KL}}(p\Vert m)
 +\tfrac12D_{\mathrm{KL}}(q\Vert m),\quad m=(p+q)/2.
\end{equation}
由于“偏离旧生成器”不等于“信号更复杂”，还报告归一化频谱熵 $H(p)/\log_2K$，以及
源与海洋背景功率直方图交集 $\sum_k\min(p_k,n_k)$。

\subsection{条件注入消融与选型}
每个训练部署使用 4000 个样本，所有模型训练 2000 步，SNR 从 $[-12,12]$ dB 均匀采样。
选型只依据 MB03\_03：FiLM 验证 SI-SDRi 为 5.35 dB，高于拼接的 5.17 dB 和交叉注意力的
4.99 dB。普通 256 样本 MB03\_04 测试上三者分别为 5.39、5.30 和 5.11 dB，无条件模型
为 5.00 dB。因此测试集确认了选择，但没有参与选择。

固定 0 dB 时，FiLM 相对相同无条件输出增加 $0.34$ dB（$[0.21,0.48]$），拼接增加
$0.15$ dB（$[0.02,0.27]$），交叉注意力增加 $0.01$ dB（$[-0.08,0.10]$）。FiLM 与任务
结构匹配：背景频谱天然指出哪些子带特征应衰减、放大或平移；其浅层乘加调制保留音频证据。
拼接必须重新学习压缩加倍后的特征，交叉注意力则要从粗粒度小时频谱中估计对齐关系，其额外
自由度在当前数据量下没有得到回报。这是与结果一致的机制解释，而非因果证明。

\subsection{广分布信号实验}
主分布实验固定输入 SNR 为 0 dB，每个信号族使用 128 个 MB03\_04 留出样本，共 768 个；
两个模型的海洋波形、源波形、时间戳和 SNR 完全配对。

全部样本上，基线为 5.36 dB，FiLM 为 5.70 dB，配对增益为 $0.34$ dB。条件增益与 JS 的
相关系数为 $-0.085$；从最低 JS 五分位的 0.54 dB 降至最高五分位的 0.00 dB。因此，
“与旧生成器距离越远，海洋先验越有用”的解释不成立。

频谱熵更有解释力。增益与熵的相关系数为 0.145；最高熵五分位提升 $+0.80$ dB
（$[0.47,1.17]$）。按信号族看，带限噪声提升 $+0.54$ dB（$[0.19,0.92]$），脉冲列提升
$0.47$ dB（$[0.16,0.79]$），调频信号提升 $0.43$ dB（$[0.08,0.82]$）。FiLM 因而在多类
信号上利用了先验，对弥散目标收益最大；原始 JS/KL 距离并非决定变量。

\section{子小时真实背景实验}
第二层证据把重建背景替换为连续原始录音，同时保留注入的合成目标。因此它能在真实声景中用
完整信号和噪声真值检验分离，却尚未检验自然发生目标的泛化。

实验固定历史覆盖为 1 小时，对应 720、120、60 或 6 个因果历史步。对目标窗 $t$，
模型只能读取 $S_{t-H:t-1}$，背景目标直接取真实波形 $N_t$。在该窗内注入广分布合成源，
$x_t=N_t+\alpha s_t$，因此信号与噪声真值仍完全干净。四种分辨率共享绝对片段时刻与注入种子。

GRU 最多预训练 2500 步。由于短窗海洋频谱具有很强持续性，零残差初始化对应 step 0 的
persistence 预测；只有学习检查点降低 MB03\_03 的预测 MAE 时才替换它。选中预测器后将其
冻结，FiLM 分离器至少训练 3000 步、最多 5000 步，仅按 MB03\_03 SI-SDRi 选择检查点，最后
一次性在 MB03\_04 评估。这样分离损失不能暗中破坏预测准确率。

\section{真实事件上的无参考评估}
\label{sec:real-events-zh}
第三层证据把合成测试目标替换为自然发生的标注事件。真实事件录音没有隔离的目标和背景声轨，
因此无法计算 SI-SDR，也无法完整识别波形保真度。这一层只回答更窄的问题：预测条件是否能在
没有明显保真失败的前提下改善语义事件移除。我们采用 DCLDE 2013
北大西洋露脊鲸数据集\cite{gillespie2019dclde}：把连续 2 kHz 单声道 WAV 切成 8 秒片段，
并按录音日而非片段划分。确定的上扫声标注构成正样本；负样本排除全部确定或可能事件及其
前后 2 秒。平衡清单包含 5292 个训练、2696 个验证和 2676 个测试片段。只有干净的训练/验证
背景会被加入局部合成上扫声来监督分离器。匹配条件实验为每个目标读取此前 8 个 8 秒、30 带
频谱；文件开头不足 64 秒因果历史的片段从两组同时排除，最终留下 1225 个真实正测试片段，
且它们都不参与检查点选择。残差 GRU 把验证 MAE 从 persistence 的 2.081 dB 降至 1.921 dB
（改善 7.67\%），随后冻结。BS-RoFormer 与 FC-BSR 共享样本、种子、迁移权重、2500 步预算和
仅验证集选点规则；只有 FC-BSR 通过 FiLM 接收预测。两者受控验证 SI-SDRi 分别为 13.871 和
13.925 dB。

依据学习式无参考分离评价\cite{grais2019referenceless}和近期语义无参考指标
\cite{xiao2024clapscore}的思想，我们单独训练事件二分类器，在验证日做温度校准后冻结。
其测试 AUROC、平均精度和 F1 分别为 0.9704、0.9738 和 0.9196。对分离器事件估计
$\hat e$，强制满足 $\hat n=x-\hat e$，再构造
$y_g=\hat n+10^{g/20}\hat e$，其中
$g\in\{-60,-30,-24,-18,-12,-6,0\}$ dB。可信输出应降低 $\hat n$ 的事件概率、让
$\hat e$ 保留事件证据、随 $g$ 增大单调恢复判别概率，并尽量不改动标注区间外的样本。
恒等输出（$\hat e=0$）和全归事件（$\hat e=x$）用于排除投机解。

\section{证据解释与实用性}
三层证据支持的是逐层嵌套、而非可以互换的结论。代理实验选择 FiLM 并证明受控完整真值收益；
连续真实背景实验说明因果时间先验能帮助未见过的真实背景分离，但四种尺度中有三种选择了
persistence，故不能概括为学习动态普遍必要；真实事件实验说明收益能迁移到匹配 BS-RoFormer
之外的语义移除，但其保真代价和缺失声轨排除了无条件保真或部署结论。

工程门槛要求：总体 SI-SDRi 不低于 5 dB；输入 SNR 不高于 0 dB 时改善至少 3 dB；
更强输入的绝对目标 SI-SDR 不低于 8 dB；前端 RTF 小于 1。FiLM 通过全部四项。
批量评估 RTF 为 0.0040；完整分块前端在 RTX 3060 上处理 10 秒 WAV 的 RTF 为 0.043。
这些检查证明计算可用性，而非现场部署就绪。现场部署仍需多站点、多季节证据，以及隔离的真实
声轨或更强的部分真值。

\section{本地应用}
仓库包含验证集选出的约 1 MB FiLM 检查点和不依赖前端框架的本地 Web 应用。用户上传最近 24 行小时级
TOL 与当前 WAV；应用校验并归一化历史、预测当前频谱、对重叠波形块执行分离，并提供目标
信号和残余海洋背景的试听与下载。页面同时绘制预测频谱，展示时长、延迟与 RTF。所有请求
都停留在 localhost，不会把录音或历史发送给远程服务。

\section{局限性}
真实波形实验消除了代理背景限制，但注入目标仍为合成信号，且全部录音来自同一站点。训练录音
只有 12 小时；10 分钟尺度仅留下 60 个独立下一窗样本，不足以训练灵活 GRU。在提出部署结论前，
还需加入多站点、多季节、多训练种子，以及真实船舶、生物和声呐目标。

六类合成信号显著扩展了原生成器，但 JS 散度与频谱熵仍只是频谱摘要，不能表达语义类别、
长时结构和录音设备效应。信号族结论必须在真实船舶、生物、声呐、天气和人为事件上复验，
才能用于生产模型选择。

\section{结论}
\method{} 给出了从声景历史到声音分离的具体、抗泄漏路径及可用本地界面。分层证据产生三个
不同结论：完整真值的受控实验选择 FiLM，并得到 $+0.34$ dB 配对增益；连续真实背景实验表明
四种尺度的因果时间条件都能改善分离，5 秒尺度增益为 $+1.226$ dB，但学习动态仅在该尺度优于
persistence，因而不能证明复杂预测器普遍必要；真实标注事件实验表明 FC-BSR 的语义移除优于
匹配 BS-RoFormer，且没有可检出的事件声轨证据损失，但区间外改动略有增加。预测条件在逐步
提高真实性的实验中均表现出价值，不过现有证据仍不支持无条件保真或现场部署结论。
